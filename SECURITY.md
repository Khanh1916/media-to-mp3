# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of **Media to MP3** seriously. If you discover a vulnerability or security bug, please follow these steps:

1. **Do not create a public GitHub issue.** Public disclosure puts users at risk.
2. Report the vulnerability privately via GitHub Security Advisories at:
   `https://github.com/Khanh1916/media-to-mp3/security/advisories/new`
   Or email the maintainers directly at `khanhnn@users.noreply.github.com`.
3. Provide details including:
   - Type of vulnerability
   - Steps to reproduce / proof-of-concept
   - Potential impact
4. We will acknowledge receipt of your report within 48 hours and coordinate a fix and advisory.
